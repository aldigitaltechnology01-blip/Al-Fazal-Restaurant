AL FAZAL FAMILY RESTAURANT — DEPLOYMENT NOTES

1. Upload ALL CONTENTS of this ZIP directly to the GitHub Pages publishing root.
2. index.html must be at the root beside styles.css and app.js.
3. Keep the assets folder and all files inside it unchanged.
4. GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root).

- Respond: Using Respond to Webhook Node

  (No trailing slash.)
